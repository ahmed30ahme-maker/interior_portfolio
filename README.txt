# Interior Designer Portfolio — Quick Start

A responsive bilingual (English/Arabic) portfolio website made with plain HTML, CSS, and JavaScript. No build tools are required.

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. An internet connection is required for the Google Fonts and Unsplash sample photography.

## Personalize before publishing
1. In `index.html`, replace “Ahmed Hassan” with your name and update the About section.
2. In `script.js`, replace `your-email@example.com` in `CONTACT_EMAIL` with your real email. The contact form opens the visitor's email app; it does not send directly from the website.
3. Replace the sample project names, descriptions, and photography with your own projects. The current images are remote sample images from Unsplash and may not represent your work.
4. Update the page title and description in the `<head>` of `index.html`.
5. Test both languages, the project filters, project popups, and the mobile menu.

## Publish for free with Netlify Drop
1. Go to https://app.netlify.com/drop
2. Sign in or create a free Netlify account if prompted.
3. Drag the extracted `interior_designer_portfolio` folder (the folder containing `index.html`, `style.css`, and `script.js`) onto the upload area. If the upload tool asks for a ZIP, upload `interior_designer_portfolio.zip` instead.
4. Wait for deployment. Netlify will provide a public URL ending in `netlify.app`.
5. Open the URL on your phone and share it with clients. You can rename the site in Netlify's site settings if the name is available.

## Alternative: GitHub Pages
1. Create a public repository on https://github.com/
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open repository Settings → Pages.
4. Under build/deployment, select deploy from a branch, choose `main` and `/ (root)`, then save.
5. After deployment, GitHub Pages displays the public site URL in the Pages settings.

## Notes
- Hosting is free on the providers' free tiers, subject to their current terms and limits.
- A custom domain is optional and usually costs money.
- This is a static site; no server or database is needed.
- Contact form uses `mailto:` and requires the visitor to have an email app configured. For a proper web form, connect a form service such as Netlify Forms.
